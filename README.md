# Ecopop Interativa (ecopopr-app)

[![R + Shiny](https://img.shields.io/badge/R%20+%20Shiny-%23276DC3?style=flat&logo=r&logoColor=white)](https://ecopopr.shinyapps.io/Ecologia_Interativa/)[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.6954166.svg)](https://doi.org/10.5281/zenodo.6954166) ![GitHub last commit](https://img.shields.io/github/last-commit/ecopopr/ecopopr-app) ![GitHub activity](https://img.shields.io/github/commit-activity/m/ecopopr/ecopopr-app)   



O app **Ecopop Interativa** é uma plataforma interativa voltada para o ensino de ecologia de populações. Desenvolvido para servir como recurso didático adicional, o app permite que estudantes realizem simulações para explorar mecanismos e resultados de modelos populacionais de forma intuitiva e divertida.

🔗 **Acesse o App:** <https://ecopopr.shinyapps.io/Ecologia_Interativa/>

------------------------------------------------------------------------

## Overview

Desenvolvido em **R + Shiny**, o projeto possui código aberto e incentiva a colaboração coletiva para se tornar uma referência em material didático na ecologia.

## Principais Funcionalidades

- **Simulações Interativas:** Explore modelos populacionais complexos através de parâmetros ajustáveis.
- **Visualização Dinâmica:** Gráficos gerados em tempo real para facilitar a compreensão dos conceitos abstratos.
- **Recurso Educacional:** Focado em traduzir a matemática por trás da ecologia para uma experiência prática.

## Instalação e Execução Local

Para rodar o aplicativo localmente, você precisará ter o R instalado.

1.  **Clone o repositório:**

    ``` bash
    git clone <https://github.com/ecopopr/ecopopr-app.git>
    ```

2.  **Instale as dependências:** No console do R, execute:

    ``` r
    install.packages(c("shiny", "tidyverse", "distill"))
    ```

3.  **Execute o App:**

    ``` r
    shiny::runApp("ShinyEcology/app")
    ```
